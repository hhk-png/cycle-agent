> 从概念到原理,从框架到实现,从评测到安全,从部署到未来——

---

## 这是一份什么样的教程?

AI Agent 正在成为大模型时代的核心抽象:它不再是被动回答问题的聊天机器人,
而是能**感知环境、制定计划、调用工具、积累记忆、并与其它智能体协作**的自主系统。
理解 Agent,不能只停留在「用框架拼一个 demo」。

这份教程的目标是让你**真正懂 Agent**:

- 它是什么、为什么在 2023 年后爆发、与 RAG / Workflow / MCP 的区别;
- 它的核心循环(感知-思考-行动-观察)背后有哪些工程设计;
- 工具调用、记忆管理、上下文工程、规划、反思、多智能体协作、MCP 的原理与取舍;
- 如何评测一个 Agent、如何让它安全、如何把它部署到生产;
- 以及——**亲手实现一个能运行的、工程化的 mini-agent**,把抽象概念变成可执行代码。

第 07 章配套的代码在 [`mini-agent/`](mini-agent/):零 npm 依赖、Node 24 原生运行
TypeScript、54 个测试用例 + 6 个可运行演示(对话 / 工具自愈 / 多智能体 / MCP / 评测 /
客服评测),离线即可跑通全部验证。第 15 章(附录 B)是它的工程手册。

## 快速开始

### 方式一:先读,再动手

按章节顺序阅读,到第 07 章时运行配套代码:

```bash
cd mini-agent
# 无需 npm install!(零依赖)

# 类型检查
npx tsc --noEmit

# 验证正确性(54 个用例)
node --test "tests/*.test.ts"

# 跑六个演示
node examples/chat.ts
node examples/math-agent.ts
node examples/team.ts
node examples/mcp-demo.ts
node examples/eval-agent.ts
node examples/eval-support.ts
```

### 方式二:直接跑 mini-agent

如果你更想「先跑起来再看代码」:

```bash
cd mini-agent
node examples/chat.ts        # 对话:工具调用 + 长期记忆 + 上下文
node examples/mcp-demo.ts    # 通过 MCP 协议调用外部程序
node examples/team.ts        # 多智能体协作
node examples/math-agent.ts  # 工具错误自愈
node examples/eval-agent.ts  # 评测 harness:数据集 + 断言 + 报告
node examples/eval-support.ts # 客服 Agent 评测(第 16 章附录 C):4 类用例 + 安全断言
```

## 学习建议

1. **第 01–02 章是理论基础**——「Agent 是什么」与「Agent 循环」是一切的地基。
2. **第 03、04、05 章是三大支柱**——工具调用、记忆与上下文工程,几乎每个 Agent 都离不开。
3. **第 07 章配合 `mini-agent/` 源码精读**,把每个概念和代码行对应起来。
4. 每章的「对照 mini-agent」小节是刻意安排的桥,帮你把抽象概念映射到具体实现。
5. 被术语绕晕 / 想快速复习:翻第 14 章附录 A 术语表,它标注了每个术语对应的章节。
6. 想改 mini-agent / 查 API / 做练习:读第 15 章附录 B。
7. 想从头到尾做一个真实系统:读第 16 章附录 C 端到端案例,把 03/04/05/10/11/12 串起来。
8. 被概念绕晕 / 想看常见坑:翻第 17 章附录 D FAQ;遇到「系统行为怪异」想排查:
   第 19 章附录 F 反模式目录(症状→根因→修复);想系统延伸阅读:第 18 章附录 E;
   想「该按什么标准做决定」:第 22 章附录 I 原则速查(与反模式互为镜像)。
9. 想了解最新生态:第 06、09、13 章梳理了 2026 年的框架、协议与趋势。
10. 想补地基:提示词怎么写 → 第 20 章附录 G;向量检索/向量库/RAG 调优 →
   第 21 章附录 H。

> 注:Agent 生态迭代极快。教程里描述的是 2025–2026 年的主流架构与工具,
> 具体 API 参数以官方文档为准。mini-agent 是教学用的简化实现,不代表任何真实框架的代码。
