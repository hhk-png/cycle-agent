## 3. 框架与工具(以官方文档为准)

| 框架 | 一句话定位 | 何时去读 |
|---|---|---|
| **LangChain** | 链式抽象的框架鼻祖;LangGraph 是 LangChain 团队针对 Chain 静态化的重构 | 熟悉其生态、或从链式迁移到图式时 |
| **LangGraph** | 显式状态图,企业级复杂工作流的事实标准 | 需要状态/检查点/人工介入时 |
| **CrewAI** | 角色化多智能体,上手最快 | 快速原型、内容管线 |
| **OpenAI Agents SDK** | 循环型 harness,handoff + 三层护栏 | 绑定 OpenAI、要生产护栏 |
| **Claude Agent SDK** | 深度自主 Agent,内置工具 + MCP 最全 | 编码 Agent、系统级访问 |
| **Google ADK** | 协议覆盖最全(MCP/A2A/ACP),多模型 | 需要协议互操作 |
| **AutoGen / AG2** | 对话式多智能体开创者 | 研究、已有系统维护 |
| **LlamaIndex** | RAG / 数据框架之王 | 检索型 Agent |
| **Smolagents** | 代码优先的 Agent(用代码行动而非 JSON) | 想理解「代码即行动」 |
| **Dify** | 中文友好的低代码 Agent 平台,RAG 管线开箱即用 | 想快速搭业务 Agent、少写代码 |
| **Coze** | 字节的 Agent 平台,插件生态丰富,面向非程序员 | 免写代码搭 bot、复用现成插件 |

> 框架会变——本书第 06 章已经提醒:框架是「当时最优」的封装,不是「永远正确」的真理。
> 读框架文档时,问自己:「它的核心抽象是什么?换成别家对应什么?」

## 6. 持续学习:到哪里跟上变化

Agent 领域迭代极快,「跟上变化」本身就是一项技能。几个可靠的信号源:

1. **官方发布**:Anthropic / OpenAI / Google 的工程博客与规范仓库
   (MCP、A2A 的更新都在各自的 GitHub org 里);
2. **顶会论文**:NeurIPS / ICML / ICLR / ACL 的 LLM-Agents 方向;
3. **开源生态**:GitHub 上的框架仓库的 README 与 changelog,
   比二手文章更及时、更准确;
4. **社区综述**:每年都有新的 Agent 综述论文,用它们做「年度刷新」;
5. **本书第 13 章**的「五个技术方向」与「七个开放问题」——如果你在找研究方向,
   那里全是选题。

## 7. 给读者的最后提醒

资源清单的宿命是「部分过时」,所以记住三条:

1. **原理读论文,方法读指南,参数读文档**——按这个优先级分配阅读时间;
2. **框架半年一变,模式十年不变**——优先掌握第 02 章的模式语言与第 05 章的上下文工程,
   它们才是这本书想让你带走的东西;
3. **读十篇不如跑一个**——把 mini-agent 改一个工具、加一个测试,
   比读十篇框架博客更能建立直觉。

> 至此,正文章节与附录到此结束。愿你带着「原理 + 代码」的双线知识,
> 在 Agent 的世界里做出既强大又可信任的系统。
