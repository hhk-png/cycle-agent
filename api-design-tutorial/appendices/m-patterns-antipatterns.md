# 附录 M：API 设计模式与反模式速查

> 这不是“最佳实践清单”，而是一张“问题 → 模式 → 代价”的索引。每个模式都有适用条件，误用会变成反模式。

## M.1 按问题选模式

| 问题 | 模式 | 代价 |
|---|---|---|
| 资源有复杂生命周期 | 聚合根 + 子资源 + 动作资源 | 端点增多 |
| 动作难以资源化 | 冒号动作 / 命令资源 | 工具链兼容性 |
| 单例配置 | 单例资源 | 易与集合混淆 |
| 批量操作 | 批量资源 + 逐项结果 | 事务语义复杂 |
| 复杂查询 | 查询资源 / QUERY / 持久化查询 | 缓存困难 |
| 长任务 | 202 + 操作资源 | 状态管理 |
| 多消费者通知 | 事件 + Webhook | 幂等/顺序 |
| 大文件 | 预签名 URL + 分片 | 安全/清理 |
| 多客户端字段差异 | BFF / GraphQL | 治理成本 |
| 多服务聚合 | BFF / Federation | 故障处理 |
| 多租户 | 租户声明 + 强制过滤 | 全链路改造 |
| 高并发写 | 预占 + 队列 + 最终一致 | 复杂度 |
| 离线 | 变更日志 + 同步游标 | 冲突解决 |
| 快速原型 / 内部工具 | BaaS / 自动生成 API + 默认拒绝 | 契约绑定数据库 |
| 公开 API 但已有数据库直出 | 稳定视图 + 网关 + 迁移路线 | 双层维护 |
| 发布统计但不泄露个体 | 差分隐私 + 聚合阈值 + 预算 | 精度与预算管理 |
| 多方联合计算 | MPC / 洁净室 + 输出控制 | 通信、延迟与流程 |

## M.2 资源模式

### 聚合根

```text
/orders/{orderId}
/orders/{orderId}/items
```

不变量由聚合根维护。适合订单、账户、文档。

### 子资源

```text
/customers/{id}/addresses
```

适合从属关系明确、生命周期依附的资源。

### 动作资源

```text
POST /orders/{id}/cancellation
POST /orders/{id}/refunds
```

适合动作需要独立状态、审计、重试。

### 冒号动作

```text
POST /orders/{id}:cancel
```

适合瞬时动作、无独立资源。

### 单例资源

```text
GET /organizations/{id}/settings
```

适合全局唯一配置。

### 操作资源

```text
POST /video-transcodes → 202 + /operations/op_123
```

适合长任务。

### 批量资源

```text
POST /orders/bulk
```

响应逐项结果，明确原子性。

### 查询资源

```text
POST /orders/search
```

适合复杂查询条件，牺牲缓存语义。

### 导出资源

```text
POST /exports → 202 + /exports/exp_123
```

适合大数据量导出。

### Webhook 订阅资源

```text
POST /webhook-subscriptions
```

适合管理回调生命周期。

## M.3 查询模式

### 游标分页

```json
{
  "data": [...],
  "pagination": { "nextCursor": "...", "hasMore": true }
}
```

适合大数据量、无限滚动。

### Keyset 分页

```sql
WHERE (created_at, id) < (?, ?)
ORDER BY created_at DESC, id DESC
```

适合深分页、稳定排序。

### 稀疏字段

```http
GET /orders/{id}?fields=id,status,total
```

适合移动端省流量，但增加权限/缓存复杂度。

### 展开

```http
GET /orders/{id}?expand=customer,items.product
```

适合减少往返，但要限制深度/数量。

### 过滤白名单

```text
status, createdAt, customerId
```

防止任意列过滤和注入。

### 快照游标

```text
cursor + snapshotId
```

适合导出/对账的一致视图。

## M.4 写模式

### 幂等键

```http
POST /payments
Idempotency-Key: ...
```

适合创建/支付/退款等非幂等写。

### 乐观并发

```http
PATCH /orders/{id}
If-Match: "v42"
```

适合读多写少、冲突低。

### 条件更新

```sql
UPDATE stock
SET reserved = reserved + ?
WHERE available >= ?;
```

适合库存、余额等原子扣减。

### 预占/确认/释放

```text
RESERVED → CONFIRMED / RELEASED / EXPIRED
```

适合库存、额度、座位。

### Outbox

```text
业务表 + outbox 同事务 → 异步发布
```

适合“写库成功、发消息失败”。

### Saga

```text
本地事务 + 补偿
```

适合跨服务长事务。

### 批量部分成功

```json
{
  "summary": { "total": 3, "succeeded": 2, "failed": 1 },
  "results": [...]
}
```

适合批量导入，需明确原子性。

## M.5 异步与事件模式

### 操作资源

```text
202 + Location + Retry-After
```

适合长任务。

### Webhook

```text
POST 回调 + 签名 + 重试 + 去重
```

适合外部异步通知。

### 事件信封

```json
{
  "id": "evt_...",
  "type": "order.paid",
  "time": "...",
  "data": {...}
}
```

适合多消费者。

### 消费者幂等

```text
if event.id processed: skip
else: process + record
```

适合至少一次投递。

### 死信队列

```text
失败 → 重试 → DLQ → 人工
```

适合 poison message。

### 事件溯源

```text
事件序列 → 状态
```

适合审计、金融、复杂领域。

## M.6 安全与运行模式

### 默认拒绝 + 行级安全

```text
RLS/Security Rules 覆盖所有暴露面 + 匿名角色无权限 + 跨租户测试
```

适合 BaaS/自动生成 API；没有默认拒绝，生成器会把整个数据库变成攻击面。

### 对象级授权

```text
每次访问检查 tenant/owner
```

防止 BOLA。

### 字段级过滤

```text
按角色返回不同表示
```

防止字段级越权。

### 令牌绑定

```text
DPoP / mTLS
```

防止令牌泄露。

### 消息签名

```text
对 method + target-uri + headers + body digest + timestamp 签名
```

适合跨组织、Webhook、网关改写与审计；验证顺序为先验签后执行。

### 确定性序列化

```text
原始字节 / JCS / 确定性 CBOR
```

适合签名、幂等指纹与去重；不要依赖 Protobuf 序列化字节。

### 密码敏捷与混合 PQC

```text
算法可配置 + 密钥 ID + 双签名窗口 + 混合密钥交换
```

适合后量子迁移与算法轮换；代价是测试矩阵与体积增加。

### 隐私预算

```text
按数据集 + 租户 + 时间窗记账；耗尽返回 PRIVACY_BUDGET_EXHAUSTED
```

适合可重复查询的分析 API；预算必须覆盖所有查询入口，不能只在一个服务里记。

### 聚合阈值 + 补抑制

```text
最小群体 k + 小格抑制 + 补抑制 + min/max 特殊处理
```

适合报表/统计 API；k-匿名与补抑制提高攻击成本，但不提供形式化上界。

### 远程认证

```text
TEE report + measurement 校验 + nonce 防重放 + 策略版本
```

适合在不可信基础设施上处理敏感明文；不做认证等于相信一个黑盒。

### 安全聚合

```text
客户端裁剪/加噪 → 聚合器只看到总和
```

适合联邦学习；安全聚合不等于差分隐私，仍需预算与防投毒。

### 限流组合

```text
租户 + 用户 + 端点 + 成本
```

防止单点绕过。

### 舱壁

```text
每个依赖独立连接池
```

防止故障扩散。

### 背压

```text
队列上限 + 拒绝 + 降级
```

防止 OOM。

### 缓存分级

```text
浏览器 → CDN → 网关 → 应用
```

按数据敏感性设计。

### 灰度

```text
按权重/租户/Header 分流
```

降低发布风险。

## M.7 反模式目录

| 反模式 | 症状 | 根因 | 修复 |
|---|---|---|---|
| CRUD 直出 | URL 是表名，PUT 可改金额 | 把数据库当领域 | 聚合建模、动作资源 |
| 万能聚合 | 响应巨大、权限混乱 | 边界缺失 | 拆分资源/BFF |
| 动词堆叠 | `/getOrders/doCancel` | RPC 习惯泄漏 | 资源/动作规范 |
| 自增 ID | 可枚举、泄漏规模 | 图省事 | UUIDv7/ULID/前缀 |
| 所有错误 200 | 监控失效、客户端难判断 | 怕报错 | 状态码 + 错误码 |
| 400 包打天下 | 无法区分校验/冲突/权限 | 错误分类缺失 | 400/409/422 分工 |
| 无幂等 | 重试重复扣款 | 忽略网络 | 幂等键 |
| 无超时 | 线程耗尽 | 信任网络 | 分层超时 |
| 无限重试 | 重试风暴 | 没有预算 | 退避+预算+熔断 |
| 多层重试 | 流量放大 | 各层都重试 | 单层重试/预算 |
| 缓存无租户 | 数据泄露 | 键设计错误 | 租户键 |
| 缓存全 public | 私有数据泄露 | 一刀切 | private/no-store |
| 游标可解析 | 越权/注入 | 明文游标 | 签名/加密 |
| 无分页上限 | 数据库被打爆 | 信任客户端 | limit 上限 |
| 同步长任务 | 超时/重复 | 架构错误 | 202+操作资源 |
| Webhook 无签名 | 伪造通知 | 忽略安全 | HMAC/非对称签名 |
| Webhook 无重试 | 丢事件 | 不可靠假设 | 退避+DLQ |
| 事件当命令 | 多消费者重复执行 | 语义错误 | 事件只表达事实 |
| 内部 API 无版本 | 静默破坏 | “自己人”假设 | 契约/兼容 |
| 网关写业务 | 难测试/难回滚 | 职责错位 | 业务下沉 |
| BFF 写业务 | 分布式单体 | 边界错位 | BFF 只聚合 |
| 文档即契约 | 实现漂移 | 无 schema/CI | 契约优先 |
| 契约只写成功 | 错误路径缺失 | 乐观设计 | 错误 schema |
| 只测 happy path | 上线即事故 | 测试不足 | 矩阵测试 |
| 只看平均延迟 | 尾延迟被掩盖 | 指标错误 | 分位数 |
| 高基数指标 | 监控爆炸 | 标签滥用 | 分层/采样 |
| 无 SLO | 无法权衡 | 运维缺失 | SLI/SLO/预算 |
| 免费层无限 | 成本失控 | 增长优先 | 配额/防滥用 |
| 计量与账单不一致 | 客户投诉 | 双口径 | 统一事件源 |
| 签名后解析再序列化 | 验签偶发失败 | 未保留原始字节 | 签原始字节或 JCS |
| 盲信 JWT `alg` | 算法混淆/伪造 | 未做允许列表 | 固定算法与密钥类型 |
| 密钥无 `kid` | 无法平滑轮换 | 临时方案 | `kid` + 双密钥窗口 |
| Protobuf 字节当规范化 | 签名/指纹不一致 | 误以为序列化确定 | 业务字段 + JCS/CBOR |
| 压缩泄露秘密 | BREACH | 压缩 + 秘密 + 攻击者输入 | 禁用/隔离压缩 |
| 无 PQC 盘点 | 迁移失控 | 没有 CBOM | CBOM + 风险排序 |
| 定价与价值脱节 | 流失/亏损 | 成本加成 | 价值/用量组合 |
| LWW 覆盖并发写 | 用户修改莫名消失 | 用时间戳裁决 | 版本号/CAS/业务裁决 |
| 多区域无 fencing | 旧主恢复后双写 | 只靠超时切主 | 租约 + fencing token |
| 跨区强一致当免费 | 写延迟暴涨 | 忽略 PACELC | 明确一致性/延迟取舍 |
| 读到旧数据当不存在 | 客户端重复创建 | 无会话保证 | 读己之写令牌/粘性 |
| 指标无口径版本 | 同名指标对不上 | 定义漂移 | 版本 + owner + 对拍 |
| 指标 API 无 data-through | 消费者不知道数据是否完整 | 只返回数值 | 截止时间 + 质量 |
| 语义层只服务 BI | API 另写一套 SQL | 双口径 | 同一语义层取数 |
| 冷启动不计入 SLO | 突增时 P99 爆表 | 只看平均值 | 冷启动比例 + 预置并发 |
| 边缘做强一致计数 | 计数不一致 | 误用边缘 KV | 回源/单写者 |
| WASM 插件无 ABI 版本 | 升级即崩 | 无契约 | 版本化 + 能力授权 |
| 形式化规格过期 | 验证的是旧设计 | 规格不维护 | 同仓库 + 评审 + 失效日期 |
| 数据库直出无 RLS | 匿名读全表 | 默认放行 | 默认拒绝 + 覆盖测试 |
| service_role key 进前端 | 全库权限泄露 | 分不清公开/管理密钥 | 仅服务端 + secret 扫描 |
| 视图绕过 RLS | 权限策略形同虚设 | 视图默认 definer | `security_invoker` + 版本核对 |
| 自动生成 API 当公开契约 | 改表即破坏客户 | schema 未解耦 | 稳定视图 + 网关 + 版本 |
| “匿名化”= 去姓名 | 准标识符重识别 | 误解匿名 | 泛化/k/DP + 评估 |
| k-匿名当形式化保证 | 同质性/背景知识击穿 | 把门槛当上界 | DP 或查询审计 |
| ε 剧场 | 写了 ε 但没算敏感度/组合 | 参数装饰 | 敏感度 + 机制 + 预算审计 |
| TEE 不做远程认证 | 信任自称安全的黑盒 | 省略认证 | measurement + nonce + 策略 |
| 洁净室无输出控制 | 等于复制数据 | 只做“不出域” | 最小群体/DP/审批 |
| 日志/trace 泄露原始值 | 主接口脱敏、旁路泄露 | 可观测性未脱敏 | 日志分级 + 采样 + 审计 |
| 本地时间无时区 | 跨时区差几小时 | 把“墙上时间”当时刻 | 时刻 + IANA 时区 + 本地日期分开 |
| DST 缺口/重叠无策略 | 排班/账期随机偏移 | 忽略时区规则 | 明确顺延/拒绝/选偏移 |
| 金额用浮点 | 0.1+0.2 对不上 | 图省事 | 最小单位整数或十进制字符串 |
| 金额无币种 | 多币种混加 | 单币种假设 | `{amount, currency}` |
| 硬编码两位小数 | 日元/第纳尔错误 | 只考虑人民币/美元 | 按 ISO 4217 exponent |
| 百分比/基点混用 | 费率差 100 倍 | 字段名含糊 | `rate`/`percent`/`basisPoints` 分开 |
| 数值无单位 | 千克/磅混淆 | 单位靠上下文 | 数值 + UCUM/SI 代码 |
| 自增 ID 对外 | 可枚举、泄露规模 | 数据库直出 | UUIDv7/ULID/前缀 ID |
| 解析 ID 前缀/时间 | 耦合生成策略 | 把 ID 当结构 | 视为不透明 |
| 游标明文可改 | 越权/注入 | 图调试方便 | 签名/加密 + 绑定查询 |
| 语言标签用 `zh_CN` | 客户端匹配失败 | 混淆 locale 与 BCP 47 | `zh-Hans-CN` |
| 字符串长度按字节不说明 | emoji/CJK 被截断 | 未定义口径 | 字节/码点/字形簇写清 |
| 同意当布尔 | 无法撤回/限定目的 | 把合规当开关 | 同意资源 + 生命周期 |
| FHIR 搜索当 SQL | 链式查询拖垮库 | 低估搜索复杂度 | 索引 + 深度/超时/分页上限 |
| 银行回调当真相 | 丢回调/乱序导致错账 | 只依赖推送 | 回调 + 查询兜底 + 对账 |
| TMF 实体直出 | 内部模型被标准绑架 | 无防腐层 | 适配层 + 内部领域模型 |
| OPC UA 每请求建会话 | 握手开销/订阅丢失 | 把会话当连接 | 会话复用 + 重连 + 订阅恢复 |
| Sparkplug retained 当真相 | 过期状态被当实时 | 误解 MQTT 保留消息 | 出生/死亡 + 序列号 + 时间戳 |
| OTA 无签名/回滚 | 变砖/供应链攻击 | 只做下载 | 签名 + A/B + 回滚 + 灰度 |

## M.8 决策表

### 分页

| 条件 | 选择 |
|---|---|
| 需要跳页 | Offset（限深） |
| 无限滚动 | Cursor |
| 大数据深分页 | Keyset |
| 导出 | 异步 + 文件 |
| 一致视图 | 快照游标 |

### 异步

| 条件 | 选择 |
|---|---|
| 结果立即可得 | 同步 |
| 长任务 | 202 + 操作资源 |
| 多消费者 | 事件 |
| 外部通知 | Webhook |
| 实时进度 | SSE |

### 授权

| 条件 | 选择 |
|---|---|
| 职责清晰 | RBAC |
| 动态条件 | ABAC |
| 关系/共享 | ReBAC |
| 集中策略 | OPA/Cedar |
| 多租户 | 令牌租户 + 强制过滤 |

### 协议

| 条件 | 选择 |
|---|---|
| 公开/合作伙伴 | REST/HTTP |
| 内部高性能 | gRPC |
| 多端字段差异 | GraphQL/BFF |
| 异步集成 | 事件 |
| 实时双向 | WebSocket |
| 单向推送 | SSE |

### 一致性与多区域

| 条件 | 选择 |
|---|---|
| 单用户多设备，冲突少 | 版本号/CAS |
| 需要读己之写 | 会话粘性 + 版本令牌 |
| 关键资源不允许覆盖 | 单写者 + 业务裁决 |
| 协作编辑 | CRDT/OT |
| 全局多活 | 按租户/键单写者 + 复制 |
| 数据驻留 | 区域内多活，不跨区故障转移 |
| 故障切换 | 租约 + quorum + fencing |
| 允许陈旧读 | 本地读 + 陈旧度上界 |

### 运行时

| 条件 | 选择 |
|---|---|
| 短请求、突发流量 | FaaS |
| 长任务、稳定高吞吐 | 容器/批处理 |
| 低延迟鉴权/缓存 | 边缘函数 |
| 强一致写 | 常驻服务 + 数据库 |
| 第三方扩展 | WASM 插件沙箱 |
| 需要连接池 | 常驻服务/连接代理 |
| 大对象传输 | 对象存储 + 预签名 URL |

### 数据库即 API / BaaS

| 条件 | 选择 |
|---|---|
| MVP / 内部工具 / 低运维 | BaaS + 默认拒绝 + 备份 |
| 内容型站点 | Headless CMS + 字段权限 |
| 公开 API / 强监管 / 复杂工作流 | 稳定视图 + 服务层 + 网关 |
| 已有数据库直出、要收紧 | 固定视图 → 网关 → 关键写服务化 |
| 多租户 | tenant claim + RLS + 跨租户测试 |
| 需要计量计费 | 自建计量点，不依赖生成器 |

### 隐私技术

| 条件 | 选择 |
|---|---|
| 发布统计、可重复查询 | 差分隐私 + 预算 |
| 只发布粗粒度报表 | 最小群体 + 补抑制 + 审计 |
| 多方联合统计 | MPC/PSI 或洁净室 + 输出控制 |
| 不可信基础设施处理明文 | TEE + 远程认证 |
| 密文上的简单聚合 | 部分同态/近似同态 |
| 设备端训练 | 联邦学习 + 安全聚合 + DP |
| 数据共享/测试 | DP 合成数据或受控共享协议 |
| 隐藏网络元数据 | OHTTP + Privacy Pass |

### 变更暴露

| 条件 | 选择 |
|---|---|
| 新功能逐步可见 | Release flag + 金丝雀 |
| 比较两种实现效果 | Experiment flag + 曝光日志 |
| 依赖故障快速关闭 | Kill switch + 独立通道 |
| 按套餐开放能力 | Permission flag + 授权/计费事实源 |
| 新旧存储切换 | Migration flag + 双写/回填/对账 |
| 删除字段/改类型 | 新版本，不用开关 |
| 高风险迁移 | 暗发布 → 金丝雀 → 全量 |
| 弃用旧端点 | Sunset + brownout + 迁移看板 |

### 控制平面

| 条件 | 选择 |
|---|---|
| 多云/外部资源 | Terraform Provider |
| 集群内资源 | CRD + Operator |
| 持续部署与漂移修复 | GitOps |
| 已有资源纳管 | `terraform import` / 收养流程 |
| 多工具共存 | 明确字段所有权 + server-side apply |
| 删除有外部副作用 | finalizer + 删除保护 + 对账 |
| 配置与密钥 | 加密 state / External Secrets |

## M.9 基础语义与行业垂直模式

### 时刻 + 时区 + 本地日期

```json
{
  "occurredAt": "2026-11-26T02:15:30Z",
  "timeZone": "Asia/Shanghai",
  "localDate": "2026-11-26"
}
```

适合跨时区业务、账单、排班、审计；代价是字段更多，必须说明三者关系。

### 金额对象

```json
{ "amount": 12990, "currency": "CNY" }
```

适合所有金额；代价是调用方必须解包，且要按币种 exponent 解释最小单位。

### 单位值

```json
{ "value": "37.0", "unit": "Cel" }
```

适合医疗、工业、科学、物流；代价是需要单位换算与未知单位处理。

### 不透明前缀 ID

```text
ord_01J9Z6Q8K3W7V2M4N5P6R7S8T9
```

适合对外资源；代价是比自增整数长，且需要生成/排序策略。

### 签名游标

```text
base64url(payload) + "." + base64url(hmac)
```

适合分页/导出；代价是游标有 TTL，且不能跨查询复用。

### 同意资源

```json
{
  "id": "cons_123",
  "status": "AUTHORISED",
  "permissions": ["ReadBalances", "ReadTransactions"],
  "expiresAt": "2026-12-31T23:59:59Z"
}
```

适合医疗、开放银行、广告/数据共享；代价是同意生命周期、撤回传播与审计复杂。

### 能力声明

```json
{
  "resourceType": "CapabilityStatement",
  "fhirVersion": "4.0.1",
  "rest": [{ "mode": "server", "resource": [] }]
}
```

适合标准密集行业；代价是声明与实现必须持续对拍。

### 命令信封

```json
{
  "commandId": "cmd_123",
  "name": "setTargetTemperature",
  "parameters": { "value": 22 },
  "expiresAt": "2026-11-26T02:20:30Z"
}
```

适合设备/工业/汽车；代价是需要确认、超时、幂等、离线队列与审计。

### 数字孪生

```json
{
  "desired": { "targetTemperature": 22 },
  "reported": { "targetTemperature": 21 },
  "version": 42
}
```

适合离线设备与车队；代价是冲突解决与状态收敛。

### 标准适配层

```text
外部标准契约 → 适配器/防腐层 → 内部领域模型
```

适合 FHIR、开放银行、TM Forum、OPC UA；代价是多一层映射与一致性测试。

### 决策表

**时间表示**

| 条件 | 选择 |
|---|---|
| 记录事件发生时刻 | RFC 3339 UTC + 可选本地日期/时区 |
| 用户预约的墙上时间 | 本地日期时间 + IANA 时区 |
| 生日、账期日 | `YYYY-MM-DD` 日期 |
| 超时、TTL | 秒/毫秒整数 |
| 订阅周期 | 日历时长（`P1M`）+ 锚点规则 |
| 跨时区排班 | 本地时间 + 时区 + 日历版本 |

**金额表示**

| 条件 | 选择 |
|---|---|
| 单一币种、内部 | 最小单位整数 |
| 多币种、公开 API | `{amount, currency}`，金额用最小单位或十进制字符串 |
| 需要人类可读 | 十进制字符串 + 币种 + 精度 |
| 大额、跨语言 | 字符串编码，避免 2^53 |
| 汇率 | 十进制字符串 + 来源 + 时间 + 方向 |

**ID 方案**

| 条件 | 选择 |
|---|---|
| 对外、不可枚举 | UUIDv7 / ULID + 前缀 |
| 需要时间排序 | UUIDv7 / ULID / Snowflake |
| 不能泄露时间 | UUIDv4 / 随机 |
| 数据库分片 | Snowflake / 带机器位 |
| 外部系统映射 | 内部 ID + `externalIds` |
| 分页 | 签名游标，不是资源 ID |

**语言与地区**

| 条件 | 选择 |
|---|---|
| 内容语言 | BCP 47 标签 |
| 格式化偏好 | locale（BCP 47） |
| 时区 | IANA 名称 |
| 币种 | ISO 4217 |
| 搜索 | 按语言配置分词/排序 |
| 回退 | 明确回退链，不静默失败 |

**行业标准接入**

| 条件 | 选择 |
|---|---|
| 医疗互操作 | FHIR + Profile + 术语 + SMART |
| 开放银行 | 区域标准 + FAPI + 同意 + 对账 |
| 电信 | TM Forum Open API + SID + 订单编排 |
| 工业 | OPC UA / Sparkplug B + 设备身份 |
| 汽车 | VSS / SOME/IP / UDS + OTA + 安全 |
| 标准与内部模型 | 始终加适配层 |

## M.10 沙箱、测试数据与实验模式

### 保真度阶梯

```text
L0 静态示例 → L1 契约 Mock → L2 状态化 Mock
→ L3 隔离沙箱 → L4 影子/回放 → L5 生产测试模式
```

按测试目的选择层级；不要用 L1 证明集成正确。

### 契约 Mock 对拍

```text
同一组消费者契约测试 → Mock 跑一次 → 沙箱跑一次 → 比较结构/状态码/错误码
```

适合契约优先、前后端并行；代价是维护两套环境。

### 测试时钟

```text
应用 Clock 接口 + 沙箱时间偏移 + 固定种子
```

适合计费、试用、过期、定时任务；代价是数据库/第三方可能绕过应用时钟。

### 数据工厂 + 租户隔离

```text
每个测试：独立 tenant + 固定 seed + 场景构造器 + 按租户清理
```

适合集成/契约测试；代价是需要清理覆盖所有存储。

### 场景化沙箱

```text
POST /__sandbox/scenarios { name, ttl } → 稳定触发超时/失败/异步延迟
```

适合联调与演示；代价是场景与真实行为漂移。

### 开关分层

```text
release / experiment / ops / permission / migration / pricing
```

不同类型有不同生命周期、默认值和审批；不要用一个布尔值表达所有意图。

### 稳定分桶

```text
bucket = hash(flagKey + salt + unitId) % 10000
```

适合灰度与实验；代价是换盐会导致跳组，必须记录盐版本。

### 暗发布 / 金丝雀

```text
影子流量（不返回） → 5% 真实租户 → 25% → 100%
每步看 SLI，失败自动回滚
```

适合高风险发布；代价是流量放大与样本代表性要求。

### 实验曝光

```text
首次曝光记录 + 主要指标 + 护栏指标 + SRM 检查
```

适合产品/行为实验；代价是缓存、重试、异步与计费污染。

### 防缓存串味

```text
缓存键 = path + query + tenant + variant + capabilitiesVersion
共享缓存不缓存按用户分桶的响应
```

适合所有开关影响响应的场景；代价是缓存命中率下降。

## M.11 控制平面模式

### spec/status 分离

```text
spec：用户期望，只读于控制器
status：实际观测，只写于控制器
observedGeneration：status 对应哪版 spec
```

适合 CRD/声明式 API；代价是状态更新频率与 etcd 压力。

### 控制器收敛

```text
observe → diff → act → requeue
水平触发、幂等、可重入、有界重试
```

适合 Kubernetes Operator；代价是调试与可观测性要求高。

### finalizer + 删除保护

```text
删除请求 → 标记 deletionTimestamp → 清理外部资源 → 移除 finalizer
```

适合有外部副作用的资源；代价是 finalizer 卡死会导致对象永久 Terminating。

### 导入/收养

```text
terraform import / kubectl apply → 读取远端完整状态 → plan 为空
```

适合遗留资源纳管；代价是无法导入的资源需要明确边界。

### 漂移对账

```text
期望状态 vs 实际状态 vs 记录状态 → 报告/自动修复/人工批准
```

适合 GitOps/Terraform；代价是字段所有权冲突。

### GitOps 字段所有权

```text
Git 管 spec，控制器管 status，HPA 管 replicas
用 server-side apply field manager / ignoreDifferences 隔离
```

适合多工具共存；代价是配置复杂、需要持续审计。

### Terraform Read 反映远端

```text
Read：查询远端 → 写回 state；404 → RemoveResource
```

适合所有 Provider；代价是必须处理最终一致与限流。

## M.12 如何使用这张表

1. 先用“问题”定位模式；
2. 读“代价”，确认可接受；
3. 检查反模式表，避免已知坑；
4. 用决策表做初选；
5. 用附录 A 做完整评审；
6. 用 ADR 记录理由。

模式不是答案，约束才是。
