# 附录 H：安全与隐私检查清单

## H.1 认证

- [ ] 调用方类型已分类。
- [ ] 认证机制与调用方匹配。
- [ ] 令牌短期有效。
- [ ] 支持轮换与吊销。
- [ ] 校验签名、`iss`、`aud`、`exp`、算法。
- [ ] 拒绝 `alg: none`。
- [ ] 公共客户端使用 PKCE。
- [ ] 不在 URL/日志中放令牌。
- [ ] 高风险操作二次认证。
- [ ] 服务间使用 mTLS/工作负载身份。
- [ ] 密钥不硬编码。
- [ ] 泄露响应流程存在。

## H.2 授权

- [ ] 功能级授权。
- [ ] 对象级授权（逐资源）。
- [ ] 字段级授权/输出过滤。
- [ ] 租户 ID 来自可信令牌。
- [ ] 管理面与数据面分离。
- [ ] 默认拒绝。
- [ ] 角色/策略可审计。
- [ ] 委托/模拟有记录。
- [ ] 越权测试覆盖。
- [ ] 数据层强制隔离（RLS/视图）。

## H.3 输入

- [ ] 类型/长度/范围校验。
- [ ] 白名单。
- [ ] 拒绝/忽略未知字段策略明确。
- [ ] 防 mass assignment。
- [ ] 防 SQL/NoSQL/命令/模板注入。
- [ ] 防路径穿越。
- [ ] 防 XXE。
- [ ] 防反序列化漏洞。
- [ ] 限制嵌套深度/数组大小。
- [ ] 限制请求体大小。
- [ ] SSRF 防护。

## H.4 输出

- [ ] 不返回内部字段。
- [ ] 不返回堆栈。
- [ ] 不返回他人数据。
- [ ] 敏感字段脱敏。
- [ ] 错误信息最小化。
- [ ] 正确 `Content-Type`。
- [ ] 防 XSS（如返回 HTML）。
- [ ] 防批量导出滥用。
- [ ] 日志脱敏。

## H.5 资源消耗

- [ ] 限流。
- [ ] 配额。
- [ ] 并发限制。
- [ ] 分页上限。
- [ ] 查询复杂度限制。
- [ ] 超时。
- [ ] 批量上限。
- [ ] 成本预算（AI）。
- [ ] 防 DDoS。
- [ ] 过载降级。

## H.7 传输与配置

- [ ] 强制 HTTPS。

- [ ] TLS 1.2+。

- [ ] 不暴露版本信息。
- [ ] 关闭调试端点。
- [ ] 默认配置安全。
- [ ] 基础设施即代码。
- [ ] 配置扫描。

## H.8 多租户

- [ ] 令牌含租户声明。

- [ ] 缓存键含租户。
- [ ] 搜索索引含租户过滤。
- [ ] 对象存储隔离。
- [ ] 队列隔离。
- [ ] 限流按租户。
- [ ] 日志按租户。

- [ ] 备份/删除按租户。

## H.9 AI / Agent

- [ ] 工具权限最小化。
- [ ] 高频/高风险操作需确认。
- [ ] 提示注入防护。
- [ ] 不可信内容与指令分离。
- [ ] 工具输出校验。
- [ ] 防 confused deputy。
- [ ] 工具来源可信。
- [ ] 数据外泄防护。
- [ ] 模型版本可追踪。
- [ ] 轨迹审计。
- [ ] 评估集覆盖对抗场景。
- [ ] 人工兜底。
- [ ] 令牌不透传给下游，逐服务换取 audience 正确的令牌；校验 `iss` 与 `aud`。
- [ ] MCP 2026-07-28 的无状态模型不依赖 `Mcp-Session-Id`；旧版会话仅作兼容层，短 TTL、绑定主体、尽快迁移。
- [ ] `server/discover` 的版本、能力与扩展经过校验；未知版本明确失败，不静默降级。
- [ ] 每个请求的 `_meta` 版本/能力经过校验，不能由客户端伪造授权。
- [ ] 本地 MCP Server 的启动命令、目录与权限经过确认。
- [ ] 工具列表变化触发重新审核；发现结果有来源校验与缓存 TTL。
- [ ] `resource_link` 与外部抓取有 allowlist 与私网拦截。
- [ ] 工具注解（只读/破坏性/幂等/开放世界）与真实行为一致。
- [ ] 支付类工具验证金额、商户、币种、过期时间与一次性 nonce。

## H.15 密码学与后量子

- [ ] TLS 1.2+，优先 TLS 1.3；弱套件、压缩与重协商已禁用。
- [ ] 证书自动轮换、到期告警、吊销路径可用；网关到源站仍加密。
- [ ] mTLS 身份能映射到服务/租户，证书与信任根有轮换演练。
- [ ] 需要端到端完整性的 API/Webhook 使用消息签名，覆盖方法、目标 URI、关键头部与 body digest。
- [ ] 签名验证有 `keyid`、算法允许列表、时间窗、重放缓存，且先验签后执行。
- [ ] Webhook 使用 Standard Webhooks/RFC 9421 或等价标准；密钥按租户/订阅隔离并可轮换。
- [ ] JWT 严格校验 `alg`/`kid`/`iss`/`aud`/`exp`/`nbf`/`typ`；拒绝 `none`、未知 `crit`、外部 `jku`/`x5u`。
- [ ] 高价值 API 使用 DPoP 或 mTLS 绑定；Refresh Token 旋转并检测重用。
- [ ] 密钥在 KMS/HSM/受控 secret 管理中，不在代码、日志、URL；有泄露响应 runbook。
- [ ] 有 CBOM/算法清单，覆盖 TLS、证书、JWT、Webhook、代码签名、SDK 与数据归档。
- [ ] 后量子迁移按数据寿命与合规要求排序；至少试点混合密钥交换（如 X25519MLKEM768）。
- [ ] 契约支持算法协商、密钥 ID、双签名窗口与可操作错误；测试新老客户端与中间设备。
- [ ] 更完整的工程细节见[附录 AD](ad-cryptography-pqc.md)。

## H.16 数据库即 API / BaaS

- [ ] 默认拒绝；匿名角色对未授权表/集合返回空或错误，而不是全量数据。
- [ ] RLS/Security Rules 覆盖所有暴露面，并有跨租户、跨用户越权测试。
- [ ] 视图不绕过底层 RLS（`security_invoker` 或等价机制）。
- [ ] `SECURITY DEFINER` 函数固定安全 `search_path`，且只授予必要角色。
- [ ] service_role/admin key 不进入客户端、日志、URL 或错误信息。
- [ ] 列级权限阻止 `select=*`、GraphQL introspection 与管理端泄露敏感字段。
- [ ] 实时订阅按租户/资源授权，权限变更后能断开或重新认证。
- [ ] 文件桶、下载 URL、图片处理有访问控制、类型/大小校验与过期。
- [ ] 边缘函数使用最小权限角色，不原样转发不可信请求头。
- [ ] 有语句超时、最大行数、连接池与实时扇出上限。
- [ ] 迁移按 Expand–Contract 管理，公开视图与内部表解耦。
- [ ] 更完整的设计见[附录 AF](af-database-as-api-baas.md)。

## H.17 隐私增强与数据最小化

- [ ] 有威胁模型与数据分类分级；每个数据集有目的限制与保留期。
- [ ] 隐私预算/查询配额按数据集、租户与时间窗记账，可审计、可拒绝。
- [ ] 聚合接口有最小群体、补抑制与差分隐私，`min`/`max` 不泄露个体。
- [ ] 查询审计能识别差分/相减攻击；缓存不绕过预算与抑制。
- [ ] 日志、trace、指标与错误信息不含原始敏感值；遥测可关闭/采样。
- [ ] TEE 有远程认证、measurement 校验、nonce 防重放与策略版本。
- [ ] MPC/HE/FL 的安全模型、信任边界、性能与精度经过实测。
- [ ] 合成数据与洁净室有输出控制、成员推断评估与合同约束。
- [ ] 元数据保护（OHTTP/Privacy Pass）与滥用控制的取舍已评估。
- [ ] 有数据主体访问、删除、更正与撤回同意的 API 路径。
- [ ] 更完整的工程细节见[附录 AG](ag-privacy-enhancing-tech.md)。

## H.18 受监管行业 API 的安全与隐私

### 医疗健康

- [ ] 患者、医务人员、机构身份分离；患者上下文不可由客户端伪造。
- [ ] SMART scope、令牌受众、患者上下文、同意校验一致。
- [ ] 对象级与字段级授权覆盖 `Patient`、`Observation`、`DocumentReference` 等敏感资源。
- [ ] 同意撤回能传播到缓存、索引、订阅与批量导出。
- [ ] 紧急访问（break-glass）有额外认证、理由、审计与事后复核。
- [ ] `AuditEvent`/`Provenance` 覆盖读、写、导出、打印与失败。
- [ ] 批量导出有短期 URL、权限过滤、最小化、保留期与审计。
- [ ] 跨境传输、数据驻留、去标识化与再识别风险已评估。

### 开放银行

- [ ] 同意是资源，权限、账户、时间、频率、撤回状态完整。
- [ ] SCA 可恢复，认证结果以服务端查询为准，不以重定向参数为准。
- [ ] 令牌短期、绑定受众与发送方（mTLS/DPoP），可撤销。
- [ ] 支付发起与账户信息权限分离；高风险操作有二次确认。
- [ ] 回调验签、幂等、乱序处理与查询兜底完整。
- [ ] 错误不泄露账户存在性、余额或客户信息。
- [ ] 对账、争议、退款、拒付有审计与证据。

### 电信与网络 API

- [ ] 合作方身份、合同范围、客户同意与 API 权限一致。
- [ ] 号码、位置、SIM Swap 等高风险能力有反欺诈、限速与审计。
- [ ] 网络 API 会话有时限、可终止、可审计；QoS 边界写清。
- [ ] 用量、CDR、账单数据有访问控制、保留期与对账。
- [ ] 遗留 OSS/BSS 适配层不绕过认证、授权与审计。

### 工业与汽车

- [ ] 设备身份基于证书/安全元件，支持吊销与轮换；不共享密钥。
- [ ] 命令有授权、确认、幂等、过期、审计与安全联锁。
- [ ] 远程解锁、充电、制动等高风险命令有强认证与人工兜底。
- [ ] OTA 清单签名、下载 URL 短期、安装校验、回滚与灰度完整。
- [ ] 功能安全与网络安全证据（ISO 26262、ISO/SAE 21434、UNECE R155/R156）可提供。
- [ ] 设备离线、重连、时钟偏差与重放攻击有防护。

- [ ] 更完整的行业设计见[附录 AI](ai-vertical-apis.md)。

## H.19 沙箱、测试数据、实验与控制平面

### 沙箱

- [ ] 测试密钥与生产密钥使用不同签名密钥和权限，环境绑定由网关强制校验。
- [ ] 测试密钥有前缀、作用域、配额、过期、轮换与吊销；泄露可自动扫描。
- [ ] 沙箱按租户/命名空间隔离，跨租户读取返回 404，不泄露存在性。
- [ ] 沙箱不使用生产 PII；合成数据优先；脱敏数据有审批、审计与 TTL。
- [ ] Webhook 出站有 SSRF 防护：私网/回环/云元数据地址、DNS 重绑定、重定向。
- [ ] 沙箱有配额与滥用检测，防止免费算力、挖矿、垃圾注册。
- [ ] Agent 使用最小权限测试凭证，不可逆操作需人工确认并审计。
- [ ] 沙箱重置覆盖数据库、缓存、对象存储、搜索索引、队列与投递记录。

### 测试数据与实验

- [ ] 测试数据使用确定性种子、独立租户与可控时钟，不依赖生产数据。
- [ ] 测试时钟偏移记录在响应/审计中，避免测试结果被误当生产证据。
- [ ] 实验不改变公开事件 schema；如改变，必须版本化并通知消费者。
- [ ] 实验曝光日志不包含不必要的 PII，访问受控。
- [ ] 涉及定价/计费的实验经过法务、财务与公平性评审。
- [ ] 缓存键包含实验变体，避免跨租户/跨变体泄露。
- [ ] 开关变更进入审计日志，kill switch 有独立权限与演练。

### 控制平面

- [ ] Terraform state 加密存储、访问受控，绝不提交 Git；日志与 plan 输出脱敏。
- [ ] Provider 从可信 registry 安装，锁定版本与校验和，验证签名。
- [ ] CRD 的 RBAC 最小权限；集群级 CRD 有额外审批；准入策略限制危险字段。
- [ ] 控制器 service account 最小权限，不能跨租户读取资源。
- [ ] GitOps 密钥使用 SOPS/Sealed Secrets/External Secrets，Git 历史无明文。
- [ ] 容器镜像用 digest 固定并验证签名；策略阻止不可信来源。
- [ ] 删除保护、finalizer 超时、孤儿资源对账与审计完整。
- [ ] 更完整的设计见[附录 AJ](aj-sandbox-mock-test-data.md)、[附录 AK](ak-feature-flags-experiments-progressive-delivery.md) 与[附录 AL](al-infrastructure-as-api-terraform-crd-gitops.md)。
